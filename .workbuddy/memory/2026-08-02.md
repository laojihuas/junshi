## v8 上线后全 500：作用域 bug 修复（v31）+ 前端"掉线了"（commit 4b7c7f2）

**事故**：v8（v30）部署后用户反馈"没有接入AI"——根因：`semanticKws` 声明在 `if (imaKey&&imaClientId&&kbId)` 块内，而 `_debug.semantic_kws` 在块外引用 → ReferenceError → 所有请求 500 → 前端 mock 回复
**教训**：
- **esbuild 只查语法，抓不到作用域错误**；部署 Edge Function 前应跑 tsc --noEmit 类型检查（npm 网络不稳时可跳过但需人工检查块级作用域）

**端到端验证方法（可复用，无需真实用户凭证）**：
1. `GET /v1/projects/{ref}/api-keys` → 拿到完整 service_role/anon 旧版 JWT（该端点完整回显）
2. `POST {url}/auth/v1/admin/users` {email,password,email_confirm:true} + Bearer service_role + apikey → 建已确认用户（**不发邮件**）
3. `POST /auth/v1/token?grant_type=password`（**必须带 apikey header**，新版项目 auth 强制）→ access_token
4. 用 access_token 调 Edge Function（只带 Authorization，复现前端）→ 检查 200 + _debug

## ima-proxy v9：记忆与自洽修复（version 32，已部署+端到端验证）

**背景**：用户用真实聊天记录复现两个严重问题——① 02:48 AI 一字不差重复自己 02:47 的开场白（失忆）；② 02:51 AI 说"拿出真本事"后,被问"什么真本事",答"真本事没有"（自相矛盾/答非所问）。排查确认：memory_card 列存在、读写正常（线上查列清单验证），根因是**记忆卡只记"对方说的话"不记"军师自己发过的话"** + **system 角色是"顾问"不是"本人"**（默认提示词"指导专家,帮助用户撰写回复"），顾问无"人设一致"义务 → 每轮贴一条话术素材，不自洽。

**改造**（`supabase/functions/ima-proxy/index.ts`）：
1. MemoryCard 加 `recent_self_messages`；updateMemoryCard 规则追加最后一条 role=assistant 消息（与 recent_user_messages 对称，≤20 条，按 session_id 隔离）

3. 注入【你之前发过的话】；参考资料降级为"弹药"（冲突时以对话连续性为准）
4. 输出要求改 1-2 句：第一句正面回应,再允许转折；严禁自相矛盾/推翻自己/答非所问/重复
5. `isNearDuplicate`（bigram 命中 ≥0.85 或一字不差）→ 主回复后兜底重生成一次
6. `_debug` 加 `self_msgs_len`

**隔离边界确认**：记忆卡按 chat_sessions.id（好友）隔离，"小姐姐"与"小丽丽"永不交叉（用户明确要求：不要跨好友记忆；不要"history 为空就重建数据库"破坏多窗口隔离——已放弃该方案，只靠记忆卡兜底）

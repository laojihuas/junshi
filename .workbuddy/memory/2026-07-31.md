    - `metadata`：JSON 字符串 `{"name":"slug","verify_jwt":false,"entrypoint_path":"supabase/functions/{slug}/index.ts","import_map_path":"supabase/functions/{slug}/deno.json","static_patterns":[]}`

## Bug 修复：prompt-update 保存失败

- **现象**：管理后台输入提示词后点保存，弹 toast "保存失败：保存失败，请检查 app_config 表是否存在"

  3. 额外加 RLS 策略 `app_config_service_role_all FOR ALL TO service_role USING (true) WITH CHECK (true)`（双保险，配合 BYPASSRLS）

## Bug 修复（续）：42501 permission denied

- **现象**：重新保存后报 `[403] {"code":"42501","message":"permission denied for table app_config"}`，hint 提示需 GRANT
- **根因**：**表级 GRANT 缺失**（RLS 只管行级）。Management API `database/query` 以超级用户建表，Supabase 默认授权（GRANT ALL ON ALL TABLES）不覆盖手动新建的表 → service_role/anon/authenticated 对该表无任何权限
- **修复**（已执行 + 固化进 `supabase/sql/001_app_config.sql`）：
  - `GRANT SELECT, INSERT, UPDATE, DELETE ON public.app_config TO service_role`
  - `GRANT SELECT ON public.app_config TO anon, authenticated`
  - service_role 显式 RLS 全权策略（FOR ALL TO service_role USING true WITH CHECK true）
  - `NOTIFY pgrst, 'reload schema'`
- **经验**：用 Management API database/query 建的新表必须**手动补 GRANT**，Supabase 的"GRANT ALL ON ALL TABLES IN SCHEMA public"默认授权只对建表前存在的表生效
- git commit `d19331b` 已 push

## Bug 修复（续）：聊天页"秒切回好友列表"真凶（v20260731-late4，commit `397804b`）

### 用户反馈（关键新信息）
- "**并没有重新加载，一秒就切回**"——排除纯杀进程 reload 场景
- 手机、电脑都复现 → 一定有 JS 在页面可见性恢复时主动导航

### 根因（代码审查找到真凶）
- **`js/auth.js` `onAuthStateChange` 回调里，`event === 'SIGNED_IN'` 时执行 `App.navigate('friends')`**

  3. **页面切回前台 `_handleVisibilityChange` 触发 token 刷新流程**
- 回调是**异步的**（内部 `await DB.getProfile`）：页面加载后 App.init 已恢复聊天页（navigate('chat')），随后 SIGNED_IN 回调才完成 → `App.navigate('friends')` **把聊天页强制切回好友列表** → 用户看到的"秒切回"

### 修复
1. **`js/auth.js`**：onAuthStateChange 回调**彻底移除导航**（SIGNED_IN 只同步 currentUser/currentProfile；SIGNED_OUT 保留 navigate('auth') + 补 clear/clearLastView）。登录/恢复后的导航统一由 app.js 显式控制
2. **`js/app.js`**：恢复逻辑加 try/catch（Chat.open 异常不中断 init，安全回退 friends 并记日志）
3. **诊断体系**（排查兜底）：
   - `js/utils.js` 新增 `Utils.dlog(tag, msg)`：localStorage 环形日志（100 条）+ console，**不记录任何敏感信息**
   - 记录点：`ws`(init navType) / `auth-event`(每次事件名) / `nav`(每次页面切换 from->to) / `chat.open` / `init done`

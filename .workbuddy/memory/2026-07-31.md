### 关键可复用知识：无 CLI 部署 Edge Function（Management API 直接调用）
- supabase npm 包 2.110.0 的 CLI 是 **Bun 编译二进制**，在部分 Windows 机器上报 `panic: Illegal instruction`（CPU 不支持 Bun 所需指令集）→ CLI 不可用
- 替代方案（全部用 `Authorization: Bearer <sbp_pat>` 调 api.supabase.com）：
  - 列出函数：`GET /v1/projects/{ref}/functions`
  - 设置 secrets：`POST /v1/projects/{ref}/secrets`，body `[{"name":"X","value":"Y"}]`，成功返回空
  - **部署函数（云端打包，无需 Docker/本地打包）**：
    `POST /v1/projects/{ref}/functions/deploy?slug={slug}&bundleOnly=...`
    body 为 **multipart/form-data**（不是 tar！）：
    - `metadata`：JSON 字符串 `{"name":"slug","verify_jwt":false,"entrypoint_path":"supabase/functions/{slug}/index.ts","import_map_path":"supabase/functions/{slug}/deno.json","static_patterns":[]}`
    - `file`：函数源码文件（index.ts + deno.json 等），filename 用相对项目根路径
    - 注意：`/functions/{slug}/deploy` 是错误路径，正确是 `/functions/deploy?slug={slug}`
  - 官方文档端点名：v1DeployAFunction（Supabase CLI 源码 packages/api/src/generated/contracts.ts）
- 用户 token：由用户主动提供的一次性 access token，已使用完毕且未写入任何文件/仓库
